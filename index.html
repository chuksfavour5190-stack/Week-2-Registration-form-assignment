The Things I have learned

1. What does the action attribute do?

The action attribute specifies the URL or destination where the browser sends form data when the form is submitted.

2. What does the method attribute do?

The method attribute specifies how the browser submits form data. Common methods include GET and POST.

3. Why is GET commonly useful for a search form?

GET places submitted search data in the URL's query string, making search URLs easy to bookmark, copy and share.

4. Why might POST be used for a registration form?

POST sends form data in the request body and is commonly used when submitting information that creates or updates data on a server.

5. Does using POST automatically make information secure?

No. POST does not automatically encrypt information. HTTPS and secure server-side handling are needed to protect sensitive data.
